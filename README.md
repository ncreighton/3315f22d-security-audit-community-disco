# Security Audit Community Discord Bot

Discord bot for security and DevSecOps communities providing daily CVE alerts, vulnerability trivia, CTF challenge links, and security tool spotlights. Commands include /cve for latest critical CVEs from NVD feed, /quiz for security knowledge questions on OWASP Top 10 and common attack patterns, /tool for random security tool deep-dive, /ctf for active CTF competition links and team sign-ups, /pentest-tip for offensive security technique of the day, /blue-team for defensive measure spotlight, and /cert for certification study resource. Includes role-based access for premium security research feeds. Discord.py, Docker-ready, MIT license.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
